# Laboratório de Programação Orientada a Objetos

Repositório destinado à organização das **atividades e exercícios da disciplina de Laboratório de Programação Orientada a Objetos**, abordando conceitos fundamentais de **Programação Orientada a Objetos (POO)**, como classes, objetos, herança, polimorfismo, interfaces e tratamento de exceções.

![Java Badge](https://img.shields.io/badge/language-Java-red)
![OOP Badge](https://img.shields.io/badge/paradigm-Object--Oriented-blue)

---

## 📚 Sobre o Repositório

Este repositório contém as **atividades práticas desenvolvidas ao longo da disciplina**, organizadas por semana conforme o cronograma do curso.

Durante o semestre serão explorados conceitos fundamentais da programação orientada a objetos, incluindo:

- Classes e objetos
- Métodos e variáveis de instância
- Estruturas lógicas aplicadas à POO
- Coleções
- Herança e polimorfismo
- Classes abstratas
- Interfaces
- Tratamento de exceções
- Manipulação de arquivos
- Interface gráfica (GUI) e tratamento de eventos

Cada atividade estará organizada em sua própria pasta contendo o código-fonte e eventuais comentários explicativos.
